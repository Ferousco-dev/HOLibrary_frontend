# Interface specification — HOL admin operations dashboard

## UI-001 Overview

Show five server-provided operational counts first. Each count uses a text label, so colour and number are never the only indicators.

## UI-002 Operations

Present four direct, labelled destinations: circulation desk, member records, overdue follow-up, and reservations. Links remain ordinary anchors so they support keyboard navigation and browser history.

## UI-003 Staff creation

Collect staff number, email, name, access level, and department. Keep visible labels, client validation, minimum 44px action height, error notices, and a one-time temporary-password notice.

## UI-004 Responsive behaviour

Use a two-column administrative workspace at wide widths. Collapse it to one column below 900px, and collapse the form to one field per row below 560px.
