Find a member

Import a roll

A whole class at once, from a spreadsheet. Export it as CSV from Excel or Google Sheets, then bring it here. The file is checked and shown to you before a single account is created.

The columns it needs

The first line must name the columns. Order does not matter, and student_id, matric_no and identifier all mean the same thing.

Every row after the first is one member
student_id first_name last_name email department level
SEN/2025/001 Feranmi Oresajo feranmi@oauife.edu.ng Software Engineering 200

Up to 8 MB. Everyone in the file is registered as a member; a spreadsheet can never create staff.

Register one member

For a single reader at the desk. The password is generated here and shown once. Write it down for them: it is not stored in a form anyone can read back, and they must change it at first sign-in.

This sets how many books they may hold and for how long.
